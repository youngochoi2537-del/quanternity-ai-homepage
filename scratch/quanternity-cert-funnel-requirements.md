## 0. 프로젝트 전제 (실행 전 반드시 수정)

```
FRAMEWORK   = Next.js 14 App Router + TypeScript + Tailwind CSS   ← 실제 스택으로 교체
REPO_ROOT   = ./                                                   ← 실제 경로로 교체
BASE_URL    = https://quanternity.ai                               ← 실제 도메인으로 교체
```

- 정적 HTML 사이트인 경우: 각 라우트를 `/quote/index.html`, `/recommend/index.html`, `/diagnosis/index.html`, `/diagnosis/start/index.html` 로 생성하고 상태관리는 `sessionStorage` + vanilla JS로 대체한다.
- 기존 디자인 토큰(색상·타이포·라운드·그림자)이 있으면 그대로 재사용한다. 없으면 섹션 9의 토큰을 사용한다.
- **신규 npm 패키지 설치는 금지**. 날짜선택·주소검색은 기존 사이트에 이미 있는 것을 재사용하고, 없으면 네이티브 `<input type="date">`와 카카오 주소검색 스크립트(CDN)를 사용한다.

### 2.1 표시 순서 규칙 (전 화면 공통, 하드코딩)

```
27001 → 42001 → [13485: 조건부] → 9001 → 14001 → 45001
```

- **점수·가중치와 무관하게 순서는 항상 위와 같이 고정한다.** 점수는 순서가 아니라 '추천 강도 뱃지'와 '추천 문구'만 결정한다.
- **13485 노출 조건** (하나라도 참이면 노출, 아니면 카드 자체를 렌더링하지 않음):
  1. 산업분야 ∈ { `의료기기·체외진단(IVD)`, `제약·바이오`, `의료·헬스케어 서비스` }
  2. `대표 제품 또는 서비스` 입력값에 키워드 포함: `의료기기`, `체외진단`, `IVD`, `진단키트`, `시약`, `PCR`, `medical device`, `헬스케어 기기`, `임플란트`, `필러`
  3. 사용자가 `/quote`에서 직접 13485를 선택
- `/quote` 화면에서는 6종을 **모두 노출**하되, 13485 카드에는 `의료기기·IVD 대상` 회색 태그를 붙인다. (직접 선택 가능해야 하므로)

## 3. 산업분야 MECE 점검 및 재설계 (요청하신 검토 결과)

### 3.1 현행 분류의 문제점

현행 목록: `서비스업 / 교육·연구업 / 화학업 / 건설·부동산업 / 운송·물류업 / 제조업 / 공공기관 / 금융·보험업 / IT·정보통신업 / 에너지·환경업 / 농·식품업 / 유통·소매업 / 의료·제약업`

| 항목 | MECE 위반 | 근거 및 영향 |
|---|---|---|
| **공공기관** | 상호배타성(ME) 위반 — 분류축 혼재 | '공공기관'은 산업이 아니라 **조직 형태**. 국립대병원은 `공공기관`+`의료·제약업`, 한전은 `공공기관`+`에너지업`에 동시 해당 → 사용자가 무엇을 고를지 알 수 없고, 추천 로직이 분기 불가 |
| **화학업 ⊂ 제조업** | 상호배타성 위반 — 포함관계 | KSIC C20(화학물질·화학제품)은 제조업(C) 하위. 화학회사 사용자가 둘 중 무엇을 고르든 다른 결과가 나오면 안 됨 |
| **농·식품업 ⊂ 제조업** | 부분 중복 | 식품제조(C10)는 제조업, 농업(A01)은 별개 대분류. 두 개를 묶어 제조업과 병렬 배치한 것은 층위 오류 |
| **의료·제약업** | 상호배타성 위반 — 이질 결합 | 병원(KSIC Q, 서비스) + 제약(C21, 제조) + 의료기기(C27, 제조)를 한 항목에 묶음. **ISO 13485 추천 여부가 이 셋에서 완전히 다르므로 로직상 치명적** |
| **IT·정보통신업** | 부분 중복 | SW개발(J62)과 통신서비스(J61)는 ISO 42001 필요도가 크게 다름 |
| **서비스업** | 포괄성(CE) 문제 — 잔여항목 오용 | 금융·유통·교육·의료도 모두 서비스업. 실질적으로 '기타' 역할을 하면서 목록 최상단에 위치 |
| **누락** | 포괄적 완전성(CE) 위반 | 전문서비스(법무·회계·컨설팅·마케팅), 연구·시험·엔지니어링(TIC), 미디어·콘텐츠가 매핑 불가 |

### 3.2 해결 방향 — 분류축 3개 분리

산업 하나로 모든 걸 판단하려 했기 때문에 겹침이 생겼습니다. **산업 / 조직유형 / 사업 특성**을 분리하면 MECE가 성립하고 추천 정확도도 올라갑니다.

**축 C. 사업 특성 (다중선택 · Yes/No 토글 3개)**

| 문항 | 가중 |
|---|---|

## 11. 유효성 검증 · 접근성 · 반응형

**검증**
- 오류 메시지는 필드 하단 인라인, 빨간 12px. 제출 시 첫 오류 필드로 스크롤 + focus.
- 사업자등록번호 체크섬: 가중치 `[1,3,7,1,3,7,1,3,5]` 알고리즘 구현.
- 파일: MIME + 확장자 이중 검증, 50MB 초과 시 즉시 거부 메시지.

**접근성**
- 모든 카드 선택 UI는 `role="checkbox"` 또는 `role="radio"` + `aria-checked` + 키보드 Space/Enter 토글.
- 프로그레스바 `aria-valuenow/valuemin/valuemax`.
- 색상만으로 상태를 전달하지 않는다(뱃지에 텍스트 병기 — 필수/권장/선택).
- 대비비 4.5:1 이상. 다크 테마에서 muted 텍스트 대비 확인.

**반응형**
- Breakpoint: 640 / 1024 / 1280.
- 모바일에서 인증 카드 1열, 업종 카드 2열, 결과 요약 2×2.
- `/recommend` sticky bottom bar는 모바일에서 safe-area-inset 적용.

## 12. 문구·컴플라이언스 체크 (개발 시 반드시 준수)

| 항목 | 지침 |
|---|---|
| `전문가 무료 제공` | 무료 범위를 반드시 명시 — "진단 결과에 대한 **1차 검토 의견**을 무료로 제공". '컨설팅 전체 무료'로 읽히지 않게 한다. |
| `추정 준비기간` | 항상 `추정` 표기 + 하단 고지 문구 필수. 특정 개월 수를 확약하는 표현 금지. |
| 인증 취득 보장 | `취득 보장`, `100% 합격`, `최단기간`, `최저가` 등 표현 **전면 금지**. |
| 인정기관 | 인증 관련 안내 페이지에 `KAB·UKAS·ANAB 등 인정기구의 인정을 받은 인증기관 발행 여부 확인이 필요합니다` 고지 1줄 삽입. |
| 컨설팅/인증 분리 | ISO/IEC 17021-1에 따라 인증기관은 컨설팅을 제공할 수 없음. 콴터니티는 **컨설팅 제공자**임을 명확히 하고, 인증서를 발행하는 것처럼 읽히는 문구를 쓰지 않는다. |
| 개인정보 | 폼별 수집항목·이용목적·보유기간을 동의 체크박스 인근에 명시. 사업자등록증 파일 보유기간 별도 안내. |
